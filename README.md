# Lab 5 — Favorite Shopping Items

A Flutter app for managing favorite shopping items on Android and iOS. Data is stored locally with SQLite.

## Features

- Add items with name, category, price, and status validation
- Browse all items and view full details
- Toggle between Wishlist and Purchased
- Confirm before permanently deleting an item
- View wishlist-only items and their total estimated cost
- Responsive Material 3 interface and bottom navigation

## Run

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter analyze
flutter test
```
